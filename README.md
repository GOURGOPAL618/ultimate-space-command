## ⚡ **INSTALLATION**

### Option 1: Quick Install
```bash
# Clone the repository
git clone https://github.com/yourusername/ultimate-space-command-center.git

# Navigate to project directory
cd ultimate-space-command-center

# Install dependencies
pip install -r requirements.txt

# Run the application
streamlit run app.py
```

### Option 2: Manual Install
```bash
# Install packages individually
pip install streamlit==1.54.0
pip install pandas==2.3.3
pip install numpy==2.3.4
pip install plotly==6.3.1
pip install scikit-learn==1.7.2
pip install folium==0.16.0
pip install requests==2.32.5
pip install pillow==12.0.0
pip install streamlit-folium
```

## 🚀 **USAGE**

1. **Launch the app:**
```bash
 streamlit run ultimate_space_command.py
```

2. **Access in browser:**
   - Local: `http://localhost:8501`
   - Network: `http://YOUR_IP:8501`

3. **Select a module** from the sidebar and explore!
